💾 Backup dos dados
O que este backup é — e o que não é
Esta ferramenta baixa uma cópia dos dados para o seu computador. Serve para você ter um arquivo próprio, fora do servidor, que continua existindo mesmo que a hospedagem seja perdida.

Ela não substitui o backup automático do servidor, que roda diariamente em disco. São proteções contra riscos diferentes: o do servidor cobre falha de gravação; este cobre perda de acesso ao servidor inteiro.

Guardar com cuidado
O arquivo contém dados pessoais e contratuais: nomes, e-mails, preços, endereços e fotos com geolocalização. Trate-o como documento sigiloso — não deixe em pasta compartilhada nem envie por canal aberto.
